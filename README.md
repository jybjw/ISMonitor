# Internet 断网关机监控

这是一个 Windows 窗体程序，用于持续检测当前电脑是否能够连接到 Internet。

## 功能

- 可设置关机倒计时时间，默认 10 分钟。
- 可设置检测间隔，默认 10 秒。
- 可设置 Web 认证页面网址、登录账号和登录密码。
- 点击“开始检测”后持续检测 Internet。
- 一旦检测不到 Internet，会优先打开认证页面并自动填写账号密码登录。
- 如果认证页面无法打开或登录验证失败，10 秒后自动重试一次。
- 如果重试仍未恢复 Internet，开始关机倒计时。
- 倒计时期间仍持续检测网络。
- 如果 Internet 恢复，自动取消关机倒计时和认证重试。
- 倒计时归零后调用 Windows 关机命令。
- 支持最小化到系统托盘。
- 已内置专用程序图标。

## 编译

在 Windows PowerShell 中进入本目录，然后运行：

```powershell
.\build.ps1
```

脚本会使用系统自带的 .NET Framework C# 编译器生成 `InternetShutdownMonitor.exe`。

## 使用

1. 打开 `InternetShutdownMonitor.exe`。
2. 设置“关机倒计时（分钟）”。
3. 设置“检测间隔（秒）”。
4. 填写“认证页面网址”“登录账号”“登录密码”。
5. 点击“开始检测”。
6. 最小化窗口后，程序会留在托盘继续运行。

## 注意

- 程序只有在倒计时归零时才会执行 `shutdown.exe /s /t 0`。
- 关闭主窗口会退出检测程序。
- 如果程序被强制结束，内部倒计时也会停止。
- 账号密码只保存在当前运行中的输入框里，本程序不会写入配置文件。
- 自动登录使用通用表单识别逻辑：寻找常见账号输入框、密码框和提交按钮。少数特殊认证页面可能需要按页面结构单独适配。
